Secuencia Fibonacci

Calculemos una sucesión de números Fibonacci

Pero, ¿qué es esto?

La sucesión de Fibonacci es una secuencia infinita de números naturales; a partir del 0 y el 1, se van sumando a pares, de manera que cada número es igual a la suma de sus dos anteriores, de manera que: Sucesión: 0, 1, 1, 2, 3, 5, 8 0 + 1 = 1 1 + 1 = 2 2 + 1 = 3 3 + 2 = 5 5 + 3 = 8 …
